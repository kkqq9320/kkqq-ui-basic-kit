#### AI·브라우저 자동화 계약

🟢 **오너 결정 2026-08-23:** 자동화 때문에 전역 pointerup을 만들지 않습니다. 실제 UI
검사는 네이티브 `<button>`과 role/name을 찾아 click·tap·키보드로 조작하고 화면의
접근성 이름과 controlled 값을 관찰합니다. `HTMLElement.click()`을 포함한 프로그램
`click`도 계속 동작해야 하며 `tests/pressable.test.tsx`가 정확히 한 번 실행되는지 지킵니다.

WebMCP·HTTP 같은 구조화 도구는 **소비자 앱 adapter**가 등록하고, UI와 같은 도메인 명령·
검증·상태 변경을 부릅니다. 킷은 `value`/`onChange`, 직렬화 모델, 의미 있는 DOM을
제공하며 아직 draft인 WebMCP 런타임·프로바이더·전역 등록에 직접 의존하지 않습니다.
API 계약 검사는 실제 UI E2E를 증명하지 않으므로 둘을 따로 통과시킵니다. 오래 가는 규칙은
`PRINCIPLES.md` §11의 **브라우저 자동화와 AI 도구**에 있습니다.

### 파일을 가를 때 — 바이트가 같아도 문서는 깨집니다

2026-08-19에 `model/instant.ts`를 여덟으로 가르면서 증명 **둘**을 세웠습니다:

```
바이트 대조   선언 쉰셋의 본문+주석이 main과 글자 하나까지 같다
킬 행렬      변이 열하나가 before/after에서 같은 검사 이름을 죽인다 (합계 395)
```

**둘 다 통과했는데 리뷰가 서른아홉을 찾았습니다.** 둘 다 **선언 단위로만** 봅니다.

🔴 **구역 주석(`/* ---- 경계 비교 ---- */`)은 선언에 안 붙습니다.** *뒤따르는 것들
전체*에 붙는 글인데 청크는 **다음 선언의 것**으로 자릅니다. 그래서 배너가 자기 구역의
**첫 선언을 따라가고**, 그 선언만 다른 파일로 가면 배너가 통째로 따라가 남의 파일에서
없는 함수 다섯을 자기 섹션으로 선언합니다.

**그래서 배정 기준이 하나 더 있습니다 — "구역 주석이 따라갈 수 있는가."** 호출 수보다
이쪽이 결정적일 때가 있습니다.

**할 일 목록:**
1. 가르기 전에 선언 그래프를 재고(주석을 **먼저 걷고**) **비순환인지 검사**하세요.
2. 배정 초안을 만들고 **파일 사이 이음매 굵기**를 세세요 — 화살표가 딱 하나인 이음매는
   대개 잘못된 배정입니다.
3. 배럴을 남기세요. 그러면 부르는 쪽의 import이 한 줄도 안 바뀝니다.
4. 가른 뒤 **배너를 사람이 한 번 읽으세요.** 자동으로는 안 잡힙니다.
5. `위 ` · `아래 ` · `이 파일` · 옛 경로를 **부류로 grep**하세요. 사례만 고치면 남습니다.

- **감시자를 세운 뒤 "이것만 잡는 변이"를 하나 찾아 두세요.** 못 찾으면 그게 답입니다.
- **관측 시점을 바꿔 보세요.** 해제 창구의 핀 가드는 네 번 실패했는데, *"창구가 도는
  동안"* 이 아니라 **끝**을 보니 섰습니다 — 그 양이 단조라 잘못 깎은 몫이 영구히
  남습니다. 판별이 안 되면 **픽스처가 두 경우를 같게 만들고 있는지** 보세요.
- **`vi.useFakeTimers()`는 `requestAnimationFrame`도 가립니다**(실측). 그리고 reduced
  motion을 켜면 rAF가 통째로 사라져 관측이 프레임 속도에서 풀립니다.
- **환경이 가리면 경로를 바꾸세요.** 의존성 배열이 다른 계기를 알려줍니다.
- **양성 대조 문자열이 스캔 코퍼스 안에 있으면 안 됩니다.**

### 그 밖에

- **StrictMode의 초기 마운트 이중 호출은 `<StrictMode>`가 `render()`의 루트일 때만**
  켜집니다(React 19 실측). 컴포넌트가 자기 안에서 그리면 그 서브트리는 한 번만 돕니다.
- **모순을 만나면 재는 자리부터 합치세요.** 서로 다른 `render()`에서 잰 두 값은
  비교 대상이 아닙니다.
- **`import.meta.glob`의 키는 `./Foo.ts` 모양**입니다(`../tests/Foo.ts`가 아닙니다).
- **`@types/node`가 없습니다.** 검사에서 `node:fs`를 쓰면 `tsc`가 깨집니다.
- jsdom에 **`PointerEvent`가 없고**, `body`의 rect는 전부 0이며, 레이아웃이 없습니다.
